# ООО «Дельтастрой» — сайт

Статический прототип сайта компании ООО «Дельтастрой».

## В этой версии

- Главная страница + полный каталог 307 позиций.
- Ergobox: фото, модели, документы и сертификаты.
- Пеликан: модели, фото, монтажные схемы, документы и сертификаты.
- Модуль ST: фото моделей и документы.
- Термит: фото моделей Термит Профи / Профи М / Трансформер, блок поставщика, сертификаты и документация.
- Блок производителей с графическими логотипами/wordmark-знаками.
- Чат-подбор оборудования.
- Работа по договору, монтаж / шеф-монтаж / обслуживание, гарантия 1 год.
- Москва и Московская область.
- Телефон: +7 (495) 506-48-78.

## Запуск

Откройте `index.html` или запустите локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`.
